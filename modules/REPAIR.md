# Уточнение безопасности v6.9.3

AGFixer by txmui сохраняет бэкапы, защиту исходного SID/HKCU и подтверждение ремонта с отменой по умолчанию. VPN default/split-default не доказывает путь назначения и не выбирает профиль автоматически; VPN+Zapret/Unknown/Ambiguous требуют явного выбора. Клиент и активный адаптер — отдельные наблюдения.

Реальные proxy/NRPT/DNS/SCM изменения этой сборки не испытаны в VM со снимком: текущая приёмка незавершена. Mock-проверки отмены, stale plan, бэкапов/Partial не заменяют системный интеграционный тест. Не выполняйте перечисленные ниже системные сценарии на рабочей сети без согласования.

# Изменения интерфейса ремонта в v6.9.2

Новый вход сначала обследует настройки Unlocker, Zapret и доступные VPN-маршруты. Отсутствующие папки предлагается найти или указать. Нулевой план не открывает подтверждение записи: выводится состояние и выбор дальнейшего действия. Проверка сама ничего не меняет.

Основной вход: раздел **Исправления** в дереве. После просмотра всего плана в режиме стрелок появляется отдельный список действий: применить, подробности отчёта, область HKLM. Esc отменяет. В несовместимом числовом/старом режиме сохранён прежний просмотр вердикта.

Папки установки определяются отдельно: settings.json и ag_dns.exe могут быть в разных местах. Выбранный EXE должен совпадать с запущенным ag_dns и прямым EXE-действием известной задачи. При неоднозначности используется выбор папки, а не запуск случайной установки.

Списки Zapret теперь нормализуются: домены добавляются в основной list-general, точные AG-записи убираются из вторичных пользовательских/исключающих списков. В плане учитываются хэши всех проверяемых файлов. Широкие исключения/повреждённые посторонние строки не удаляются: при остаточных ошибках дальнейшая автонастройка останавливается, возможен Partial после уже выполненных шагов. Нет общей транзакции всех сетевых изменений.

Ниже сохранена техническая документация движка v6.8. Указанные там Space/A/G/M/D — клавиши прежнего экрана, в новом основном интерфейсе этим действиям соответствуют видимые пункты.

# Автоматический ремонт Express v6.8

## Одна клавиша, но известный объём изменений

Space открывает план, Enter/F применяет его один раз. Дополнительных вопросов внутри выбранных шагов нет. Esc отменяет просмотр. На маленьком экране Enter перелистывает страницы до последней: нельзя случайно подтвердить невидимую часть плана.

План строится по локальному состоянию; перед записью он пересобирается и сравнивается по SHA-256/целям. Изменился адрес прокси, профиль, список или стратегия — нужно открыть новый план. Дополнительно перед каждым удалением повторно сверяется конкретное правило NRPT, а перед отключением прокси — реестр и наличие слушателя.

## Области применения

| Шаг | Точное действие |
| --- | --- |
| Proxy | Только статический localhost/127.x.x.x/[::1] с корректным портом и без слушателя; удаляет ProxyServer, ставит ProxyEnable=0, перечитывает WinINET |
| HKLM | По умолчанию выключен; клавиша M явно добавляет подходящий машинный прокси в план. PAC/политики/работающий прокси остаются |
| NRPT | Только точные пространства googleapis.com и известные поддомены Antigravity/antigravity-unleash.goog из allowlist, с 127.0.0.53. Смешанные чужие namespaces и advanced DNSSEC/DirectAccess/IPsec правила исключены. Дополнительные DNS допустимы только у правила с меткой Unlocker |
| DnsBypassOff | Атомарно меняет только поле dns=false; остальные настройки сохраняются |
| Profile | VpnDirect выключает пять сетевых флагов; Zapret включает dns/local_proxy, выключает group_proxy/builtin_exits/own_proxy_enabled. Не меняет вход, автопатч, аккаунт и TLS |
| ZapretDomains | Добавляет Core/Login домены из domains.json в существующие general/user списки, не стирая остальные строки; с копией и проверкой результата |
| Zapret | Только локальная проверенная ALT11; путь и SHA-256 стратегии проверяются повторно; BAT целиком не запускается |
| Restart | Только две известные задачи Unlocker и ag_dns из своей папки; копия gate.json, остановка/перезапуск, проверка готовности задач и наличия своего процесса ag_dns |
| WinHTTP | Сброс на всей машине — **только в глубокой очистке**. Предварительно сохраняется winhttp dump, после сброса проверяется Direct |
| FlushDns | Clear-DnsClientCache, без дублирующего ipconfig /flushdns |
| GPUCache | В глубокой очистке при наличии — перемещение только APPDATA/Antigravity/GPUCache, не профиля/авторизации |

Запись невозможна без администратора. Для профиля, DNS-настроек, перезапуска или GPUCache IDE и GUI Unlocker должны быть закрыты **до первого изменения**. Неизвестные/отключённые задачи не включаются принудительно; ошибочная установка требует отдельного исправления.

## Диагноз и настройки — не одно и то же

Региональный отказ распознаётся по явному `region-400`/`User location is not supported`, а не по любому HTTP 400. Последние 15 событий имеют приоритет, но наличие DNS-обхода не устанавливает географию DNS-сервера, а `VPN (по сокетам): None` не исключает системный TUN. Поэтому вывод короткий и предметный: что переключить/проверить, без выдуманного доказательства.

Программа не переключает страну VPN, не включает TUN, не отменяет привязку IDE к локальному прокси и не устанавливает сторонний Unlocker. При отсутствии подходящих локальных изменений предлагает явно выбрать VPN/Zapret. Название режима не гарантирует обход, квоту или доступ к модели.

В текущем upstream штрафы маршрутов хранятся в памяти процесса; `gate.json` публикует состояние. Рабочее действие — контролируемый перезапуск своей сетевой части. Копирование/пересоздание gate.json оставлено для совместимости и не снимает ограничения Google/аккаунта.

## Копии и частичный отказ

Журнал ремонта: `%LOCALAPPDATA%\AGFixer\repairs\<время-GUID>\`.

- `before.clixml`: значения выбранного реестра с типами, выбранные NRPT-правила, хэш settings.
- `result.json`: результаты только выполненных шагов, Applied/Failed, итоговый статус.
- `winhttp-before.txt`: исходный WinHTTP, если он выбран.
- `settings.json.backup-*` и `gate.json.backup-*` лежат рядом с файлами Unlocker; списки Zapret имеют свои соседние копии; установщик службы сохраняет собственную копию службы.
- GPUCache перемещается в соседнюю `GPUCache.backup-*`.

**Applied** означает, что выбранные шаги прошли проверки. **Partial** означает остановку на ошибке: предыдущие успешные изменения могли остаться. Дальнейшие шаги не запускаются; зелёного «всё исправлено» нет.

Это не единая транзакция всей Windows. При ошибке изменения реестра выполняется локальный откат только ProxyServer/ProxyEnable, при сбоях списков/установки действует их существующий откат. Обратная запись тоже может не удаться — это выводится как ошибка. Полный автоматический откат NRPT/WinHTTP после поздней ошибки не выполняется.

Для восстановления settings/DNS/GPUCache/службы используйте прежние инструменты **A** и их проверенные копии. `before.clixml` — данные для ручного восстановления конкретного выбранного правила/значения, а не скрипт для запуска. WinHTTP восстанавливайте только после просмотра `winhttp-before.txt` под свою исходную схему; файл сам автоматически не выполняется. Не импортируйте чужие CLIXML и не запускайте команды из отчётов.

Копии могут содержать адреса и локальные пути. Не отправляйте папку repairs целиком в чат. Пакет помощи создаётся отдельно и проверяется перед отправкой.

## Что ещё проверить на настоящей Windows

Поведение WinINET refresh, редкие NRPT/CIM типы, запуск задач, права и состояние работающего VPN зависят от ОС. Локальные автоматические тесты используют моки Windows-провайдеров и реальные временные JSON/backup/journal файлы; они не являются нативным испытанием ремонта на Windows.
