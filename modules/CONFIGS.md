# Конфиги AGFixer

Раздел главного меню **«Конфиги»**:

1. **Создать конфиг Zapret или VPN** — выбрать отдельный пошаговый мастер; каждый шаг на чистом экране.
2. **Загрузить конфиг из файла — выбрать настройки** — просмотр, галочки компонентов, локальный адаптер/режим списков, итоговое подтверждение.
3. **Посмотреть конфиг** — только чтение, без применения.

Файл — обычный UTF-8 JSON, рекомендуемое имя `my.agconfig.json`, до 2 МБ.
Это данные, не скрипт. Старое расширение `.agbuild.json` также читается: расширение не определяет формат.
При загрузке номер компонента включает/выключает галочку; `A` выбирает всё; Enter завершает выбор;
`0` отменяет его. По умолчанию ничего не выбрано. Пустой выбор не применяет ничего.

## Что можно переносить выборочно

| Компонент | Что сохранится / применится | Что не переносится |
| --- | --- | --- |
| Профиль Unlocker | Пять переключателей `dns`, `local_proxy`, `builtin_exits`, `group_proxy`, `own_proxy_enabled`; URL своего прокси без реквизитов, если включён | Аккаунт, API-ключи, настройки TLS/патчера и остальные поля settings.json |
| Стратегия Zapret | Имя установленного BAT и его SHA-256; при загрузке используется существующий проверяющий установщик службы | Содержимое BAT/EXE, драйверы, команды из JSON, автоматическая загрузка Zapret |
| Списки Zapret | Домены из `list-general.txt` и/или `list-general-user.txt` | hosts, NRPT, IPSet, произвольные пути и другие файлы |
| IPv4 DNS VPN | Статические адреса либо режим DHCP | GUID/индекс исходного адаптера, IPv6, VPN-аккаунт, TUN/split-routing, конфиги WireGuard/OpenVPN/VLESS |

**VPN нужно установить и запустить отдельно.** Профиль VPN в Unlocker и DNS его адаптера —
не конфигурация самого VPN-клиента. После смены профиля Unlocker его перезапуск доступен отдельно:
«Исправления → Настроить Unlocker / Zapret / VPN DNS → Unlocker → Перезапустить маршрутизацию».

## Списки доменов

При загрузке предлагаются два явных режима:

- **Добавить из конфига, оставить свои** — стандартный безопасный вариант: исходные строки и комментарии остаются, добавляются отсутствующие домены.
- **Заменить целиком** — выбранные списки становятся списками из конфига; прежние записи и комментарии сохранятся только в backup-копии. Пустой список в таком режиме очищает соответствующий файл.

Поддерживаются DNS-имена и суффиксы, префикс ^ (точное имя), префикс . (суффикс).
При сохранении IDN переводится в punycode, # комментарии (в том числе в конце строки) отделяются.
Неизвестная запись показывает конкретный путь и номер строки; можно отменить сохранение либо
явно сохранить конфиг без списков. URL, команды, IP-адреса,
маски `*.`, пути и неизвестные поля отклоняются. При сохранении комментарии не включаются в конфиг.
При загрузке целевые списки уже должны существовать. При ошибке записи/перезапуска служба и файлы
списков восстанавливаются в пределах этого компонента; неуспешный откат явно сообщается.

## Стратегия Zapret

При сохранении пользователь выбирает локальный BAT для конфига. Это не гарантия, что выбранная
стратегия сейчас активна. При загрузке требуется файл с тем же именем и SHA-256 в папке установленного
Zapret. Не совпадает/отсутствует — остановка до первого изменения выбранных компонентов.
BAT не запускается как скрипт: существующий парсер извлекает допустимую команду winws и проверяет файлы.
Применение через SCM требует отдельного подтверждения. Доверять установленному winws и драйверу всё равно нужно.
Совпадение BAT не доказывает одинаковый состав всего Zapret или работу обхода у другого провайдера.

## DNS на другом ПК

Выберите **свой активный VPN-адаптер** при загрузке. Исходный GUID/индекс не переносится.
Сохраняются локальная копия DNS с режимом DHCP/Static и GUID, затем проверяется результат;
при ошибке выполняется попытка возврата. DHCP не заменяется адресами, выданными старой сетью.
Если VPN/политика управляет DNS или меняется адаптер во время импорта, применение может быть отклонено.

## Секреты и приватность

- Полный settings.json никогда не экспортируется, только разрешённые поля.
- URL с логином/паролем или неподдерживаемым форматом целиком исключается. В конфиге появляется
  `ProxyNeedsInput: true`; для включённого своего прокси при загрузке нужен свой URL без реквизитов.
  Если прокси требует авторизацию, настройте её отдельно в доверенном клиенте/локальном прокси.
- Адрес прокси без пароля и собственные домены тоже могут быть приватными: смотрите JSON перед передачей.
- Конфиг не зашифрован и не подписан. SHA-256 BAT — проверка совпадения, не подпись автора конфига.
- Локальные backup-копии настроек могут содержать ваши ключи и пароли. Их не отправляйте вместе с конфигом.

## Ошибки, копии, частичное применение

Перед первым изменением проверяются **все выбранные** компоненты. После подтверждения порядок:
профиль Unlocker → списки Zapret → стратегия Zapret → DNS VPN.

Это **поэтапный импорт, а не одна общая транзакция**. Если поздний этап завершился ошибкой или отменён,
ранние успешные этапы остаются применёнными. Программа останавливается и сообщает, где произошла ошибка;
возврат выполняется отдельно из копий. Не нужно считать весь конфиг неприменённым.

Журнал: `%LOCALAPPDATA%\AGFixer\imports\import-*.json`.
В нём имена компонентов, статусы и пути копий, без исходных ключей/URL/команд.
`Started` после аварийного завершения — неопределённый результат, который нужно проверить вручную.
`Applied` — этап выполнен; `FailedOrNeedsReview` — ошибка/нужна проверка; `Cancelled` — отказ на этапе стратегии.
Копии settings/DNS — рядом с настройками Unlocker; копия параметров службы — рядом с установленным Zapret.
Откат параметров службы не равен полному экспорту её ACL, триггеров и учётных данных.

Не выбранные компоненты не изменяются. Не выполняются автоматический сброс маршрутов,
чистка профиля, удаление истории, выключение защиты или отправка куда-либо.
Файлы конфигов не перезаписываются: выберите другое имя для новой версии.

## Технический формат v1

Внутреннее обозначение сохранено как `AGFixer.Build`, независимо от названия раздела «Конфиги».
Разрешены только перечисленные поля; неизвестная версия отклоняется. Минимальный пример
для уже запущенного VPN (меняет только профиль Unlocker, не устанавливает VPN):

```json
{
  "Kind": "AGFixer.Build",
  "FormatVersion": 1,
  "Name": "Профиль Unlocker для уже запущенного VPN",
  "CreatedAt": "2026-10-19T00:00:00Z",
  "Components": {
    "Unlocker": {
      "dns": false,
      "local_proxy": true,
      "builtin_exits": false,
      "group_proxy": false,
      "own_proxy_enabled": false,
      "ProxyNeedsInput": false
    }
  }
}
```

Собственный конфиг лучше создавать через «Сохранить конфиг», а не угадывать поля вручную.
Сохранение/загрузка и ошибки провайдеров протестированы локально с фикстурами; настоящие Windows
SCM/DNS/UAC и VPN на машине пользователя остаются отдельной приёмкой по ACCEPTANCE.md.

## Отдельные мастера v6.5

**Zapret:** стратегия (general/ALT2/ALT10 в естественном порядке, N/P — страницы) →
текущие доменные списки или без них → добавить профиль Zapret или без профиля → имя → сохранение.
Профиль Zapret формируется для конфига, а не копирует случайно текущий VPN-профиль.

**VPN:** VPN/TUN или свой HTTP/HTTPS/SOCKS5 прокси → без DNS или DNS активного VPN →
адаптер при необходимости → имя → сохранение. Стратегия Zapret здесь не запрашивается.
DNS и аккаунт самого VPN-клиента — разные вещи: конфиг не переносит клиент/его ключи/маршруты.

Сохранение не применяет выбранный профиль и не запускает BAT/службу. Старые файлы v1 остаются читаемыми;
при загрузке по-прежнему можно выбрать отдельные компоненты.

## Экраны v6.6

Предварительный просмотр конфига и план загрузки разбиты на страницы. В списках меню введите N/P
и нажмите Enter для перелистывания, либо номер пункта для выбора. VPN выбирается по названию,
а не по техническому InterfaceIndex; к реальному индексу он привязывается внутри программы.
Просмотр не меняет настройки. Перед применением по-прежнему есть отдельное подтверждение.
Выбор профиля Unlocker не включает разблокировку входа/автопатч и не меняет сверку TLS:
эти три пункта проверьте вручную по соответствующему гайду.

## Профиль проверки подключения (v6.7)

Новый .agcheck.json не является конфигом настроек .agconfig.json и не применяется через обычный импорт.
Он доступен в «Проверки сети и состояния → Мой путь подключения». Сохраняет режим проверки и явный адрес
HTTP/SOCKS5-прокси/локального релея без пароля. Загрузка требует просмотра и подтверждения;
Windows, IDE и Unlocker при этом не меняются. Настоящие конфиги Zapret/VPN по-прежнему применяются выборочно в этом разделе.
Подробности — CONNECTIONS.md.
