# AGFixer v6.10.4

## 6.10.6 — Y/N, понятный VPN-план и клиентские инструкции

- Убрано скрытое второе меню после плана: Y применяет просмотренный план, N/Esc отменяют, Enter не подтверждает. Многостраничный план нужно полностью просмотреть; после изменения области HKLM или размера экрана просмотр начинается заново.
- То же Y/N действует в проверке списков Zapret. Повторный вход после записи показывает актуальные списки и (Настроено), а не новое предложение применить пустой план.
- Исправлена приоритетность выражения массив+конкатенация, разбивавшая имя файла, двоеточие и статус на отдельные строки.
- Прямой VPN-профиль проверяется по стабильному хэшу settings.json и пяти настоящим boolean. Совпавший профиль не переписывается и не вызывает без причины restart/flush. NRPT, прокси и явный запрос сброса сохраняют необходимые операции. Непрочитанное состояние не называется настроенным.
- План VPN разделён на автоматические изменения, действия в самом VPN/IDE и нетронутые настройки. Внутреннее имя VpnDirect не показывается новичку.
- Убраны F1-рекламные подписи в footer; сама F1-функция сохранена.
- Добавлены восемь семейств VPN-клиентов и универсальная инструкция: отдельные режимы TUN, HTTP/SOCKS и неизвестный. Ручной выбор не превращается в подтверждение VPN-маршрута. Все 11 прежних гайдов остаются.
- Новые тесты: test-zapret-review, test-repair-review, test-vpn-clients. Системные изменения Windows и реальный запуск сторонних клиентов здесь не выполнялись.

- Сначала создаётся и проверяется временный файл, затем переименовывается без перезаписи существующего; временный файл удаляется при ошибке.

# Изменения v6 относительно v5

## Исправления
- TLS: минимум PowerShell 7.4/.NET 8 вместо ошибочного 7.2/.NET 6; проверка API AllowTlsResume.
- HTTP CONNECT: строгая версия HTTP/1.0 или HTTP/1.1; SOCKS5: отказ при пустом/обрезанном адресе.
- Дополнительное ограничение ожидания TLS через WaitAsync с токеном фазы.
- Служба: обязательный читаемый baseline, запрет переходных состояний, ожидание остановки при откате,
  проверка восстановления запуска, сохранение обеих ошибок, обработка неоднозначного create.
- Удаление службы: backup до остановки; возврат работающего состояния при отказе удаления, если возможен.
- Списки: запрет тихого повреждения не-UTF-8 текста; атомарная запись, SHA-256/backup; откат нескольких файлов и повторный запуск при отказе.
- Настройки: проверка внешних изменений перед заменой, восстановление из проверенного JSON с undo-копией.
- DNS: адреса, режим DHCP/Static, компьютер и GUID в копии; IPv4 CIM InputObject; проверки результата/откат.
  Отказ при несовпадении DNS реестра и эффективных значений; старые неполные копии не угадываются.
- Задачи: отключённые отклоняются до остановки; исходная ошибка не маскируется неуспешным перезапуском.
- Аудит: dns_ai учитывается как владелец порта; расширены имена IDE/language_server; исправлен битый текст.
- Свой прокси в настройках: отклоняются path/query/fragment.
- Launcher/run.bat: ненулевой код ошибки больше не скрывается.
- Диагностический ZIP публикуется под итоговым именем лишь после сборки; без автоматической отправки.
