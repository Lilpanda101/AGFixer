## Что такое AGFixer

**AGFixer помогает понять, почему Antigravity не подключается к модели, и исправить поддерживаемые локальные проблемы без ручного редактирования настроек.**

Вместо длинного журнала и запутанных меню:

- **Понятный результат** — что обнаружено и что можно сделать.
- **План перед изменениями** — без скрытого применения настроек.
- **Отдельные сценарии для VPN и Zapret** — без смешивания способов подключения.
- **Гайды сообщества** — инструкции и решения с указанием авторов.
- **JSON для поддержки** — диагностический файл для обращения за помощью.

> AGFixer не заменяет Unlocker, VPN или Zapret и не обещает исправить ограничения аккаунта, квоты модели или сбои серверов Google.

## Быстрый запуск

### 🪟 Windows:
1. Откройте [страницу релизов](https://github.com/txmu1/AGFixer/releases/latest).
2. Скачайте ZIP-архив AGFixer из раздела **Assets**.
3. **Полностью распакуйте** архив в отдельную папку.
4. Запустите **`run.bat`** от имени администратора.
5. Выберите нужное действие в главном меню.

> **Не запускайте программу прямо из архива.** Все файлы сборки должны находиться вместе.

### 🐧 Linux (Arch / CachyOS / Ubuntu / Debian / Fedora):
1. Склонируйте репозиторий или скачайте `run.sh` и `agfixer_linux.py`:
   ```bash
   git clone https://github.com/txmu1/AGFixer.git
   cd AGFixer
   chmod +x run.sh agfixer_linux.py
   ```
2. Запустите нужный режим:
   ```bash
   ./run.sh            # Интерактивная диагностика Zapret, Unlocker, DNS и портов
   ./run.sh --fix      # Автоматический безопасный ремонт (с бэкапом settings.json)
   ./run.sh --test     # Быстрый тест доступности Google CloudCode и AI-модели
   ./run.sh --doctor   # Потоковый анализ журналов и диагностика сбоев
   ./run.sh --rollback # Откат настроек на последнюю рабочую копию
   ./run.sh --mode zapret # Переключение в режим чистого Zapret (SmartDNS)
   ./run.sh --mode clash  # Переключение в режим Zapret + собственный прокси
   ```

## Возможности

### 🔍 Диагностика и ремонт

- Разбор отчёта Unlocker из **файла или буфера обмена**.
- Краткий результат диагностики вместо простыни технических логов.
- Проверка процессов, системного прокси, DNS/NRPT и настроек Unlocker.
- Формирование плана исправлений по найденным проблемам.
- Резервное копирование изменяемых файлов в поддерживаемых операциях.
- Проверки состояния перед применением изменений.
- Инструменты пересоздания графического кэша при проблемах с отображением Antigravity.

### 🛡️ Свой VPN и прокси

- Отдельные инструкции для **TUN/VPN** и **HTTP/SOCKS-прокси**.
- Настройка Unlocker под выбранный способ подключения.
- Распознавание популярных VPN-клиентов.
- Разделение статусов: **клиент запущен** и **маршрут через туннель подтверждён** — не одно и то же.

Встроены инструкции для следующих клиентов:

| Клиент | Инструкции |
| --- | --- |
| Happ | Выбор режима подключения и проверка настроек |
| Amnezia VPN | VPN/TUN и совместная работа с Unlocker |
| Hiddify | TUN и прокси-режим |
| v2rayN | TUN и системный прокси |
| Clash Verge Rev / Mihomo | TUN, системный прокси и маршрутизация |
| Proton VPN | VPN-подключение |
| WireGuard / AmneziaWG | Туннель и маршруты |
| OpenVPN Connect / GUI | VPN-подключение |
| Throne | TUN, System Proxy и mixed inbound |
| FlClash | TUN и системный прокси |
| Clash Nyanpasu | TUN и системный прокси |
| GUI.for.SingBox | Профили TUN и прокси |

Для остальных приложений есть вариант **«Другой клиент»**.

Названия и расположение настроек могут зависеть от версии клиента. AGFixer не устанавливает VPN-приложения, не импортирует подписки и не меняет их ключи или конфигурации.

### ⚡ Zapret

- Поиск установленной папки и возможность указать её вручную.
- Проверка доменов Antigravity в списках.
- Исправление поддерживаемых записей с резервным копированием.
- Сохранение комментариев и широких исключений.
- Инструменты работы со стратегиями без обязательной установки ALT11.

### 📚 Гайды и дополнительные инструменты

- Гайды сообщества и пошаговые инструкции.
- Сохранение и выборочное применение конфигов AGFixer.
- Работа с резервными копиями.
- Отдельный раздел **«Для опытных»**.
- Сохранение диагностического JSON в файл.
- Проверка новых версий через GitHub Releases.

### Требования

- **Windows 10 или Windows 11**.
- **Windows PowerShell 5.1**.
- Права администратора для запуска и системных исправлений.
- Интернет для внешних сетевых проверок и проверки обновлений.

## Как пользоваться

### Есть отчёт Unlocker

1. Выберите **«Открыть отчёт — файл или буфер»**.
2. Укажите источник отчёта:
   - буфер обмена;
   - локальный файл.
3. Ознакомьтесь с результатом.
4. Откройте план найденных исправлений.
5. Проверьте изменения и подтвердите их клавишей **Y**.

При открытии файла можно вставить полный путь или перетащить файл в окно ввода, если терминал поддерживает такую вставку. Пути с пробелами и кавычками поддерживаются.

Поддерживаются локальные TXT/LOG-отчёты и диагностический JSON AGFixer. Максимальный размер импортируемого файла — **10 МБ**.

Импортированный отчёт служит источником диагностических данных. Команды, пути и планы из него не исполняются как код; текущие настройки компьютера проверяются отдельно.

### Используете свой VPN

1. Выберите **«Свой VPN/TUN — настроить Unlocker»**.
2. Укажите клиент.
3. Выберите фактический режим подключения.
4. Выполните клиентские инструкции.
5. Если предложен план настройки Unlocker — ознакомьтесь с ним перед применением.

**Не путайте TUN-режим с системным HTTP/SOCKS-прокси.** Это разные способы подключения, для них предусмотрены разные инструкции.

Запущенное приложение VPN само по себе не подтверждает, что трафик Antigravity проходит через туннель.

### Используете Zapret

1. Выберите **«Zapret — списки доменов и стратегия»**.
2. Проверьте выбранную папку Zapret.
3. Откройте проверку списков и доступные инструменты.
4. Применяйте изменения только после просмотра плана.

Для отдельного открытия проверки доменов нажмите **L** в главном меню.

### Автоматических изменений не найдено

Это означает, что для выбранного действия программа не сформировала доступных исправлений. Это **не равнозначно подтверждению доступа к модели**.

При необходимости:
- выберите подходящий способ подключения — VPN или Zapret;
- откройте гайды сообщества;
- сохраните JSON для поддержки.

### Компактные окна

Интерфейс адаптируется к размеру терминала. Минимальный размер основного TUI — **32×12**.

Для комфортного просмотра рекомендуется окно **80×25 или больше**. Длинные материалы разбиваются на страницы.

## Отчёт для поддержки

Нажмите **S** или выберите **«JSON для поддержки — сохранить в файл»**.

Файл появится в папке `reports` рядом с программой:

```text
AGFixer/
├── run.bat
├── ...
└── reports/
    └── AGFixer-report-<дата>-<ID>.json
```

После сохранения программа покажет полный путь.

- Отчёт сохраняется в файл, а не копируется в буфер обмена.
- Повторное сохранение создаёт новый файл.
- Исходный сырой отчёт Unlocker не добавляется в JSON.
- Если запись невозможна, программа покажет ошибку.

**Перед отправкой проверьте содержимое.** Диагностика может содержать локальные пути, адреса и другие сведения о вашей системе.

## Безопасность

- Перед изменениями показывается план.
- Отмена не применяет план.
- Для поддерживаемых файловых изменений создаются резервные копии.
- Из импортированных отчётов не выполняются команды.
- Проверка обновлений не запускает скачанный код.
- Работающий прокси не должен удаляться только из-за наличия адреса `127.0.0.1`.
- Проверка процесса VPN не подменяет проверку маршрута.
- Сохранение JSON не означает его автоматическую отправку в поддержку.

Не применяйте изменения, если не понимаете показанный план. Для управляемых рабочих компьютеров согласуйте изменение сетевых настроек с администратором.

## Ограничения

AGFixer помогает диагностировать и исправлять поддерживаемые локальные проблемы, но:

- не предоставляет VPN, прокси или серверы доступа;
- не снимает ограничения и квоты аккаунта;
- не исправляет нехватку мощностей на стороне Google;
- не гарантирует работоспособность любой стратегии Zapret у любого провайдера;
- не считает одиночный тайм-аут доказательством блокировки провайдером;
- не считает успешное TLS-соединение подтверждением ответа модели.

### TLS на Windows 10 и Windows 11

Сетевой зонд использует возможности системного TLS-стека.

На Windows 10 штатный Schannel не предоставляет поддерживаемый TLS 1.3. В совместимом режиме может быть согласован TLS 1.2; строгая проверка TLS 1.3 может вернуть неподдерживаемую платформу.

Оценивайте результат по **фактически согласованному протоколу**, а не только по названию проверки.
