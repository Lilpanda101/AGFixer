AGFixer Linux — локальные исправления после аудита (не опубликованный релиз)

Исправлены:
1. Маркеры hostlist в комментариях и посторонних переменных больше не разрешают запись.
2. Повторные присваивания, условия и подстановки команд запрещают автоматическую запись.
3. Поддержан HOSTLIST_NOAUTO в действующей статически заданной стратегии.
4. HOSTLIST_BASE учитывается; неподтверждённые выражения отклоняются, shell не выполняется.
5. Одиночные/экранированные кавычки не приводят к ошибочному раскрытию $ZAPRET_BASE.
6. Соседний .gz не маскирует отсутствующий файл hostlist/ipset; Lua fallback сохранён.
7. @config/$config явно помечены как непроверенные, без выполнения и без ложного пустого результата.
8. --doctor от root прекращается до чтения настроек и обращения к пользовательской службе.
9. Хеш config вычисляется из прочитанных для анализа байтов; добавлена повторная проверка под блокировкой hostlist.

Проверка: 32 прежних + 16 новых = 48 тестов PASS; compileall PASS; bash -n PASS.
Новые тесты запускались до исправлений: первый набор 13 — 11 failures, 1 error;
добавочные проверки кавычек/подстановок — 2 failures до последующего исправления.
Отдельно принят штатный config.default Zapret2 после явного включения hostlist и NFQWS2.
Ни службы, ни firewall, ни реальная сеть в регрессионных тестах не изменялись.

Ограничения: статический разбор не доказывает, что процесс использует выбранный config,
не учитывает внешние shell override-файлы и окружение запуска службы.
Сложный config требует ручной проверки, а не запуска как кода.
Нет сквозного теста реальных служб на дистрибутивах, проверки Python 3.10 или Windows.
Windows-валидатор аргументов этим пакетом не исправляется.
Обычная hash-проверка не заменяет межпроцессный протокол блокировки с Zapret.

Содержимое: обновлённая папка linux/ для рабочего дерева, тесты и журнал.
Распакуйте отдельно для проверки. Не подменяет опубликованные RC-архивы и их BUILD-VERIFICATION.
Запуск: cd linux && bash run.sh
Тесты: cd linux && python3 -m unittest discover -s tests -v
