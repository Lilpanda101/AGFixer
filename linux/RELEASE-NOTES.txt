AGFixer: отдельные предварительные сборки Windows и Linux

Windows 1.11.0 RC1
- Возвращена поздняя рабочая база v13 вместо более старых модулей main.
- Выключенный WinINet-прокси не включается в очистку и повторно проверяется перед записью.
- Исправлена проверка файлов --option=value и --option value, включая fake-stun/unknown-udp.
- JSON-отчёт сохраняет суффикс версии Unlocker, задержку и состояние отложенного маршрута.
- Добавлены обнаружение winws2, CMD-пресеты, проверки Lua/blob/WinDivert-файлов.
- Служба из другой установки не перезаписывается.
- Прогрев перед сравнением отделён от трёх оцениваемых раундов.
- Нестандартные hostlist Zapret2 не переписываются; это показано как ручная настройка.

Linux 2.1.0-rc1
- Отдельные модули core, zapret_support, интерфейс и безопасные операции.
- Убрано ложное доказательство доступности модели через HTTP 400/401/403.
- Убрана безусловная замена DNS-провайдеров при провалившихся проверках.
- Добавлены план, подтверждение, приватная копия, проверка хеша, атомарная запись и откат.
- Отдельная поддержка nfqws/nfqws2, аргументов Lua/blob и счётчиков NFQUEUE nftables/iptables mangle.
- Добавлено ограниченное добавление доменов в стандартный hostlist с сохранением остальных сайтов.
- Меню и нижние горячие клавиши, индикатор длительных операций, автоотчёт при открытии меню.
- Таймаут сетевого дочернего процесса ограничивает зависание DNS/HTTPS.
- Требуется Python 3.10+, а не заявленные ранее 3.8+.

Проверено локально: 15 офлайн-наборов Windows-кода на PowerShell 7.4.7/Linux;
32 unittest Linux на Python 3.13/Linux; запуск Linux CLI/меню и раздельная упаковка.

НЕ проверено: нативные Windows PowerShell 5.1/UAC/SCM/реестр, реальные маршруты
с установленными winws2/nfqws2, реальные установки на каждом дистрибутиве.
CI для Windows PowerShell 5.1 и Python 3.10 добавлен, но удалённо не запускался.

Это RC для проверки, не обещание полностью протестированного стабильного релиза.
В Linux пока нет Windows-перебора стратегий, управления произвольными VPN/TUN
или автоматического переписывания Lua/shell-конфигов. В Windows управление
службой ограничено именем zapret и прямым запуском winws/winws2.

GitHub Release не опубликован; репозиторий не изменялся удалённо.
