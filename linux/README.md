# AGFixer Linux 2.1.0-rc1

Отдельная Linux-утилита, без PowerShell и без Windows-компонентов. Требуется Python **3.10+**, сторонние Python-пакеты не нужны. Для управления Unlocker нужна его пользовательская systemd-служба `ag-unlocker-proxy.service`.

Подходящие по базовым требованиям системы: Ubuntu 22.04/24.04+, Debian 12+, актуальные Arch/CachyOS и Fedora с Python 3.10+. Это **не список реально протестированных установок**. Debian 11 со штатным Python 3.9 не подходит без более нового Python. OpenRC, OpenWrt и нестандартные службы автоматически не управляются.

## Запуск

Распакуйте Linux-архив, откройте терминал в его папке:

```sh
bash run.sh
```

В исходном репозитории сначала перейдите в `linux/`. `pip install` и `sudo` для обычного запуска не нужны.

Меню: 1 — состояние, 2 — профиль Unlocker, 3 — Zapret/Zapret2, 4 — HTTPS, 5 — инструкции, 6 — откат. Горячие клавиши показаны внизу. Это упрощённое Linux-меню, не полный клон Windows TUI.

## Полезные команды

```sh
bash run.sh --doctor
bash run.sh --test --via unlocker
bash run.sh --test --via system
bash run.sh --test --via own
bash run.sh --fix --mode zapret2
bash run.sh --fix --mode zapret
bash run.sh --fix --mode vpn
bash run.sh --fix --mode proxy
bash run.sh --fix --mode group
bash run.sh --rollback
```

`--test` по умолчанию проверяет локальный прокси Unlocker. `--via system` — текущий системный путь, который может отличаться от пути Antigravity. `--via own` — адрес своего HTTP-прокси из настроек. `--proxy http://127.0.0.1:ПОРТ` задаёт HTTP/mixed-порт явно. Пароли не передавайте в командной строке: при интерактивной настройке proxy ввод скрыт.

Сохранены сокращения `-d`, `-t`, `-f`, `-y`; `--mode` тоже открывает подтверждаемый план настройки. Безопасное изменение поведения: `--fix --yes` **без профиля** больше не угадывает маршрут, а завершается с объяснением. `--yes` используйте только для заранее выбранного профиля.

### Что меняет профиль

| Профиль | DNS | Локальный прокси Unlocker | Дополнительный выход |
|---|---|---|---|
| zapret / zapret2 | вкл | вкл | встроенные/группа/свой — выкл |
| vpn / direct | выкл | выкл | встроенные/группа/свой — выкл |
| proxy / clash | выкл | вкл | свой HTTP-прокси — вкл |
| group | выкл | вкл | группа — вкл; нужен сохранённый ключ |

Это явные варианты настройки, не обещание их пригодности для каждого подключения. VPN-клиент, TUN и выбор сервера AGFixer не меняет. Ключи, патчер, проверка TLS и список DNS-провайдеров не переписываются.

Перед записью закройте окно настроек Unlocker. Создаётся приватная копия, затем файл записывается атомарно. Несовпадение хеша отменяет запись. Проверка хеша не является общей блокировкой для сторонних программ: не редактируйте файл одновременно.

После записи перезапускается пользовательская служба Unlocker. Если это не удалось, программа пытается вернуть прежний файл, не затирая внешние изменения. Неполный откат явно обозначается. `--rollback` применим только к последней проверяемой транзакции; неизвестные/изменённые после неё настройки не затираются.

## Zapret и Zapret2

Диагностика различает процессы **nfqws** и **nfqws2**, проверяет файловые аргументы запущенного процесса, читает состояния `zapret.service` / `zapret2.service`. Lua и shell-config не выполняются.

Проверяются NFQUEUE-правила nftables и mangle-таблицы iptables/ip6tables. Без прав или утилиты результат будет «неизвестно», а не «правил нет». Счётчики не доказывают принадлежность правила Zapret и не подтверждают работу модели.

Для стандартной установки можно отдельно подготовить пользовательский hostlist:

```sh
bash run.sh --zapret-domains --zapret-root /opt/zapret2
```

Если файл принадлежит root, **только эту операцию** запускайте с нужными правами:

```sh
sudo bash run.sh --zapret-domains --zapret-root /opt/zapret2
```

Для старого Zapret укажите его реальную папку, например `/opt/zapret`. Нужны существующие `config`, `ipset/zapret-hosts-user.txt`, MODE_FILTER=hostlist/autohostlist и `<HOSTLIST>` в config. Проверка текстовая: она не устанавливает, что именно этот config запущен.

Семь доменов перемещаются в начало, остальные записи сохраняются; создаётся копия. При `.gz`-копии, нестандартном config или ссылках запись отменяется. Пользовательские exclude-файлы только перечисляются — широкие исключения автоматически не удаляются. Перезапуск Zapret выполняйте штатным способом своей установки. Firewall, ipset, Lua и shell-конфиги автоматически не меняются.

Встроенного перебора/применения Lua-стратегий Linux пока нет. Нельзя переносить Windows ALT в nfqws2 простой заменой имени программы.

## Отчёты и время соединения

При открытии/возвращении в меню ищется последний распознаваемый TXT/LOG Unlocker на рабочем столе, включая XDG-путь. Повторное чтение ограничено: не чаще 2 секунд, до 256 записей каталога и 4 новых кандидатов за проход; файл должен перестать изменяться хотя бы на 750 мс. При удалении/ошибке сохраняется последний хороший отчёт.

Во время ожидания ввода отчёт **не обновляется в фоне**; нажмите R или вернитесь в меню. При очень большом числе файлов бюджет может ограничить поиск; откройте файл явно:

```sh
bash run.sh --report '/путь/Antigravity Unlocker — отчёт.txt'
```

Показываются задержка выбранного маршрута из отчёта, состояние «отложен/не используется» и источник замера. Старый отчёт не считается свежим ответом модели.

Активная проба измеряет **DNS + TCP + TLS + ответ HEAD**, не ICMP-пинг и не скорость генерации. Проверяются Cloudcode, Gemini API, Antigravity Unleash, сайт YouTube и gateway Discord. Модели, видеопоток и голос этими пробами не проверяются. Каждый сетевой процесс ограничен по времени; зависший DNS не должен удерживать интерфейс бесконечно.

Порт локального прокси берётся из loopback `AG_LS_PROXY` текущего процесса или файла `proxy_port` Unlocker. 53129 — только запасной вариант, не подтверждённый текущий порт. Наличие TCP-слушателя не доказывает, что это нужный процесс.

## Проверка

```sh
python3 -m unittest discover -s tests -v
```

В исходном репозитории: `python3 -m unittest discover -s linux/tests -v`.
Реальные службы и NFQUEUE в тестах не меняются. Реальные установки на перечисленных дистрибутивах требуют отдельной проверки.
